# 海報播放器

這是一個可部署在 GitHub Pages 的靜態海報播放器。圖片放在海報目錄，MP3 放在音樂目錄，開啟首頁後可以選擇要播放哪一組目錄、播放速度，以及每個檔案的播放順序。

## 使用方式

1. 將圖片放到 `poster/`、`poster1/`、`poster2/` 等海報目錄。
2. 將 MP3 放到 `mp3/`、`mp3_1/`、`mp3_2/` 等音樂目錄。
3. 在首頁選擇「海報目錄」、「音樂目錄」與「播放速度」。
4. 按「套用目錄」讀取所選目錄內的檔案。
5. 在「海報播放順序」和「音樂播放順序」中勾選要播放的檔案，並用上下按鈕調整順序。
6. 按「開始播放」，播放器會依照設定順序依序播放。

首頁設定會儲存在目前裝置的瀏覽器中，下次開啟會自動沿用。

## 新增可選目錄

編輯 `config.js`，把新資料夾名稱加入選單清單：

```js
window.POSTER_PLAYER_CONFIG = {
  posterDir: "poster",
  mp3Dir: "mp3",
  availablePosterDirs: ["poster", "poster1", "poster2", "poster3"],
  availableMp3Dirs: ["mp3", "mp3_1", "mp3_2", "mp3_3"]
};
```

首頁也有「自訂目錄...」可直接輸入未列在清單中的資料夾名稱。

## manifest.json

如果伺服器不提供目錄索引，請在每個媒體目錄放一個 `manifest.json`：

`poster1/manifest.json`

```json
{
  "files": ["poster-01.jpg", "poster-02.png"]
}
```

`mp3_1/manifest.json`

```json
{
  "files": ["music-01.mp3", "music-02.mp3"]
}
```

## 圖片與影片播放

海報目錄可以同時放圖片、影片與 PDF，例如 `png`、`jpg`、`mp4`、`pdf`。系統會把它們一起列在「海報播放順序」中，使用者可以勾選、取消或調整順序。

圖片與 PDF 會依照設定的播放秒數切換；影片會播放到結束後再自動切換到下一個項目。

也可以在「海報播放順序」中替單一圖片、影片或 PDF 設定個別秒數。留空時圖片與 PDF 會使用上方的全域播放速度，影片則會播放到結束；填入秒數後，該項目會依照指定秒數切換。

## 常用操作

- 空白鍵：暫停或繼續海報輪播
- `PageDown` / 右方向鍵：下一張海報
- `PageUp` / 左方向鍵：上一張海報
- `M`：播放或暫停音樂
- `F`：全螢幕
- 觸控螢幕點一下播放畫面：下一張海報
- 觸控螢幕快速點兩下播放畫面：暫停或繼續海報輪播
- 觸控螢幕左右滑動：切換上一張或下一張海報
## 海報語音模式

在設定畫面把「音訊模式」切換成「海報語音」後，系統會到目前選擇的海報目錄中尋找同名 MP3。

範例：

- `poster1/poster-01.jpg`
- `poster1/poster-01.mp3`

播放 `poster-01.jpg` 時會同步播放 `poster-01.mp3`，語音播放完畢後才自動切換到下一張海報。若該張海報沒有同名 MP3，系統會依照設定的播放秒數切換下一張。
